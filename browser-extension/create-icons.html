HuntMaster Extension Icon Generator

Instructions:

  1. Click "Generate Icons" to create placeholder icons
  2. Right-click each canvas and select "Save image as..."
  3. Save as icon16.png, icon48.png, and icon128.png respectively
  4. Place them in the browser-extension folder

Tip: For better icons, create your own 16x16, 48x48, and 128x128 pixel images with the HuntMaster logo or game controller icon.
